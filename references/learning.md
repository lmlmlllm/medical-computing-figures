# 有界学习与维护

仅明确learn授权执行。按科学任务+关系结构+图型选参考，疾病/作者/算法作辅助标签。每批最多10张，优先失败项和空缺。检索→身份/版本/图号/许可→相关全文/图注→整图/局部实际观察→元素关系证据→视觉表达→条件规则→去重/状态→代表规则实际绘图测试→检查点。

PubMed用于医学文献发现；出版社、PMC、正式会议集或合法作者版用于图文核对。记录原始研究/综述/会议/预印本版本，更正/撤稿检查范围；无法访问据实保留队列，换合法来源，不绕过限制。姓名用机构/共同作者/标识消歧，不合并所有Zhang M。

独立稳定案例ID；按论文+版本+图号去重，裁剪属于父图，不增加计数。分别记录元数据、正文范围、图像查看范围/清晰度/工具证据、语义完整度、许可、归档或link_only、来源版本、迁移测试。visual_only/semantic_partial不计完整图文案例。图像/代码/第三方素材许可分别核实；公开可看≠可转载。

每例回答图解决什么、为何分组/连接、布局为何合适、省略什么、歧义/局限、可迁移规则和不可迁移科学内容。记录规则增量，不把数量/自评分当能力证据。连续两批无有效增量则换方向或做迁移测试，记录瓶颈。

catalog由单一写入者合并，子代理各写独立case目录。更新用原子替换；保留失败历史和当前恢复动作。两篇未用于规则/模板开发的论文在冻结检查清单后作为迁移测试，测试后才纳入catalog；不声称模型预训练从未见过。

每次目录入库后同步 STATUS 首个二级标题之前唯一的“目录现为”摘要，并在技能根目录运行 `PYTHONDONTWRITEBYTECODE=1 .runtime/bin/python -B scripts/check_catalog_summary.py --status STATUS.md --catalog references/catalog.jsonl`。这是对当前明确句式、存储论文字符串、分类计数和最新 ID 的只读检查；失败时先修正或说明原因，再报告入库完成。它不自动回写，也不改历史段落、重审旧条目或验证科学内容。原14项检查与后来2项解析修复检查分别留存，见[检查记录](../tests/batches/catalog-current-summary-check-01/README.md)。

分别保存实际进程退出、图像查看和输出核对的证据。后续验证或独立重放成功，不能补称缺少回执的原作者调用完整完成；光栅化和作者自述也不能替代可观察的看图记录。历史日志或失败产物已丢失时明确列出缺失，不把幸存摘要称为完整留存。按冻结分母保留失败、未观察和不可判定项，再单列修复后的结果。

受控独立评分将冻结政策与候选答案分组分开管理。评分者先读原定政策并保存回执，再对已封存读图断言分类；分类封存后才曝光答案。图像优先读者仍不接收政策或预期错误。条件性疑点、确定错误、可选清晰度和未知分别计数，来源核对不得倒填初读结论。顺序偏差保留原记录，再用新评分者按原政策限定复测；同一对照不增加样本数。实际例证见[GRU-D时间条件对照](../tests/batches/grud-temporal-mask-control-01/README.md)。

旧技能只允许按任务要求选择性只读参考，不运行可能回写的脚本。新入口、配置、脚本、索引和例图独立存在；来源路径可以出现在迁移记录，运行代码不得依赖旧目录。隔离测试含旧目录拒绝读取负对照，并在相同子进程环境完成材料读取、spec、出图、修改、检查及交付。

在同一受限环境先验证真实运行时可启动，再核验实际存在的禁读材料；路径不存在不算权限拒绝。运行时修复只开放必要依赖，不扩大材料访问范围；保留启动失败与修复后的实际重放记录。

完成普通绘图即交付；learn维护在实际可用窗口持续推进，停止时保存真实状态，不能声称没有任务的后台运行。
