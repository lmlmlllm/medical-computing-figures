# One figure_spec

JSON layout used by optional helpers (another equivalent source format is allowed for custom figures):

- `figure`: `id`, `version`, `material_version`, `purpose`, `excluded_inferences`; add target size/use, proposed claims and actual limitations.
- `sources`: source-ID mapping to `url` or local `file`, exact `location` (section, paragraph/page, figure/panel, code line/result field), version and read scope. These point outside the specification to evidence.
- `semantics.elements`: `id`, `label` (newlines allowed), `aliases`, `role`, `stage`, `source_refs`; add unit, shape, level or parameter status as applicable. Role color defaults are data/model/output/training; color does not itself establish scientific meaning.
- `semantics.relations`: `id`, `source`, `target`, `type`, `direction` (directed/undirected), `stage`, `condition`, `source_refs`, `status` (confirmed/conflict/unknown/hypothesis/inference); add detailed evidence or shared-parameter conditions. For n-input operators use an explicit operator node and separate inputs.
- `semantics.claims/results`: claims and support scope; for data figures field mappings, comparators, groups, denominator, aggregation and error definition. Do not enumerate every pixel/scatter point as a biological object.
- `visual`: for the generic renderer use `type: explicit_layout_diagram` (omitted type retains this legacy default), `canvas` in drawing units, `width_mm`, `nodes` map (`box:[x,y,w,h]`, optional fill/fontsize), `edges` map (ports `from`/`to`: left/right/top/bottom; optional `via:[[x,y],…]`, label and label_at), `panels` with id/box/label, `annotations` with x/y/text/size/id. Boxes use top-left coordinates. Dedicated result and custom diagram types are rejected by the generic renderer before output writes.
- `caption`: panel roles, terms, line styles, training/inference/units/errors and limitations appropriate to this figure.
- `review`: gaps, severity, decisions/confirmation, rendering inspection details; append revision observations, not only pass flags.

Stable IDs map to SVG node and edge groups. `check_spec --compare` compares all `semantics`, including conditions and claims, order-sensitively. Reordering arrays may produce a conservative difference. It does not inspect visual labels, so view the actual rendering after a visual-only edit. Diagram helpers do not guarantee collision-free layouts.

## Physical and engineering relationships

Use distinct types for `control_setting` (specified settings to a controlled source), `wireless_energy_transfer` (power transferred without a wired connection), `electrical_conduction` (physical electrical transfer through conductive components), `electrical_stimulation` (electrical excitation delivered to tissue), and `physiological_measurement` (sensing a physiological quantity). These types are supported by the structural checker; the checker does not establish the device physics, clinical safety or existence of a feedback loop. A source-specific legend must explain each line's meaning.

An energy-transfer edge is not automatically data communication. A measurement edge is not automatically feedback control. A functional block diagram can omit a circuit's return topology only when its abstraction is explicitly stated; never label it a complete circuit schematic. Record in vivo species, ex vivo tissue, phantom/simulation and proposed clinical use separately.

Custom visual layouts may retain their own coordinate convention in `visual` and use dedicated Matplotlib code while preserving the same evidence/semantic core. Declare whether box coordinates are top-left or center-based and in mm or drawing units. Keep source URLs and locators inside `sources`; relative source paths must resolve from the actual delivered spec location.

## Check custom specs at their delivered location

Custom renderers still need per-element and per-relation sources, stages, conditions, directions and evidence status. A batch-wide source note or shorthand S01 without a source map does not meet that requirement. Retain explicit referenced dependencies (for example tied weights or a reused attention matrix) even when they are represented by labels instead of drawn lines; distinguish those from drawn edges.

Resolve every relative local source path from the final spec directory, and verify the referenced version/hash. Check completeness separately from renderer geometry: a correct-looking SVG and a passing native-object checker can coexist with an incomplete evidence record. Preserve the original test and add a new delivery revision when repairing this gap. [spatial-graph-01](../tests/batches/spatial-graph-01/README.md) records this exact failure, nine controlled metadata rejections and unchanged visual exports. Field presence and a resolving link do not prove the scientific source supports the claim.

After execution or a scope change, synchronize applicable active task/purpose, status, conditions and supporting generator fields with the evidence. Keep unexecuted operations marked as such, and preserve frozen inputs and historical reports unchanged. Prefer one authoritative current execution state instead of repeating provisional flags in each panel or output description. Remove or update inherited planning flags after rendering; historical plans belong in clearly dated snapshots. The [MultiVI delivery metadata repair](../tests/batches/multivi-missingness-01/assessment.md) preserves the original stale flags and the corrected canonical spec.

For matrix/equation figures, declare the referenced arrays, scalars, score/probability matrices and losses as semantic objects, in addition to member labels. Each relation endpoint must resolve to an object; a list containing only I1/I2/T1/T2 does not describe `labels → S → Q → loss`. Multi-input equations may use source-ID lists without drawing extra arrows, but their calculation role, direction, conditions, stage and evidence remain explicit. Record actual result fields, shapes, row/column identities, normalization sets, aggregation denominators and error meaning. Do not turn metadata completion into extra plotted results.

Display bindings must identify the scientific object and its state or iteration, not merely a matching value. Equal norms, rounded values or totals do not establish identity; aggregated or grouped displays must specify the transformation and covered members. The [MoDL mapping and active-task repairs](../tests/host/modl-three-figure-02/README.md) retain both original defects and unchanged visible outputs.

The [RAG field repair](../tests/batches/spec-evidence-01/README.md) and [matrix interface repair](../tests/batches/spec-evidence-02/README.md) preserve prior specifications and initial reports. Given synthetic arrays are inputs, not evidence for real medical similarity. Original scientific-source conflicts remain separate from a well-formed spec. Retained source comments should not be treated as executed operators; in the MedCLIP example, label-clamp prose and actual logit-scale clamping describe different things.


Rebase relative dependencies when delivering a spec inside an export directory, then resolve and hash-check them from that actual location. Test a real render using the delivered spec itself. An author input spec resolving correctly does not prove its copied export resolves. [signal-timefreq-01](../tests/batches/signal-timefreq-01/README.md) preserves18 broken references at three copied-spec locations, a separate rebasing repair and9 identical exports from a delivered-spec rerender; no new scientific reading is implied.


For attention or other normalized operators, state the score axes, scale parameter, allowed member set, normalization axis and when exclusion acts. Name the weight matrix separately from its weighted value output. Keep literal test arrays distinct from learned representations; define all-masked behavior instead of inventing an output. When values can exceed a fixed visual range, declare and visibly label the overflow policy. The attention fixture preserves a finite native-check omission and its repair; source consistency remains separate from faithful rendering of deliberately altered parameters.


For spatial/channel interfaces, declare axis order, padding, stride, size changes and channel mapping separately. Represent crop and merge as distinct operations with both merge inputs; distinguish channel concatenation from elementwise addition. Retain intermediate dimensions when grouping repeated convolutions. Index intervals need an explicit convention and provenance: a locally chosen symmetric crop is not verified author-code alignment. Shape-only outputs must not be labelled as an evaluated mask or performance result. Input changes update every dependent interface, including the final projection.


For effect-estimate displays, specify the statistical quantity, numerator/denominator comparison, adjustment, endpoint/time horizon and confidence level separately from raw event counts. Encode subgroup membership and overlap with an overall total. A reciprocal display uses 1/r and reversed reciprocal interval endpoints and preserves the original arm identity of counts. Record source rounding and omitted/unavailable information weights. A plotted diamond or adjacency cannot establish independent groups or pooling. Missing uncertainty/comparison provenance remains undecidable.


For grouped cell matrices, specify cell IDs, original biological sample IDs, condition, cell type, output-group IDs and the metadata join key separately. Record the aggregation operation and axis orientation (for example X genes×cells, H groups×cells, Y = X Hᵀ). Reassigned groups retain their source-sample provenance; unchanged group size does not establish biological replication. Missing sample identity leaves aggregation membership and independent replicate count undecidable. Preserve a failed frozen expectation and append a source-grounded correction; do not change the input or silently rewrite a checklist to manufacture a pass.


For measurement-agreement plots, declare the subject join key, reading/time-point selection, original measurement units, display conversion, signed difference and averaging rule. Record the SD denominator and limit multiplier; limits of agreement, SE and confidence intervals remain distinct. Link the semantic series to every actual data pair without treating each point as a separate biological entity. Retain source rounding and genuine text/figure conflicts; missing paired values or SD does not authorize reconstructing points or bounds. Scaling units must propagate through coordinates, summaries, axis bounds, labels and caption while preserving raw-input provenance.


For memory selection, distinguish the persistent bank, query-conditioned sampled slots, read keys, write-comparison features, payloads, positional encodings and predicted quality scores. Record capacity, batch size, draw count/replacement, normalization domain, update iteration and timing separately. A relative gate identifies its comparison entry and strictness. Map duplicate sampled IDs to the same underlying objects. If a missing-material scenario removes an input, its delivered dependency must actually omit that field; preserve known computations and mark affected decisions and post-update state unknown. Pin whether the drawing follows paper equations or a specific implementation when they disagree.


For calibration displays, declare the pairing key, analysis unit, probability/outcome fields, bin boundaries and closure, x-coordinate definition, within-bin denominator, empty-bin policy and count-axis scale. Map aggregate points to source members. Bin changes update every dependent series and label while preserving original predictions. Missing outcomes must be absent from the actual input and leave event counts/rates unknown, including in headers and captions. Distinguish consistency bands under calibration from confidence bands around an estimated curve; do not copy intervals or scores that were not computed.

## Isotonic calibration example fields
Record forecast and observation units, fitting population, tied-case weights, curve support/interpolation, band target/level, resampling order/replicate count/seed and saved-draw provenance, finite-replicate counts, quantile/boundary convention, and score formulas. Map semantic element IDs to actual SVG glyph IDs and source locators. Empty glyph lists can explicitly represent withheld missing-outcome estimates; they must not hide an available but unverified curve. The enriched CORP specs retain original specs and77 byte-identical scientific/visual exports; source fields were separately replayed after initial acceptance.

## Rank-rule comparison fields
For a conformal operator illustration, record class calibration membership, model-score role/polarity, less/tie counts, denominator, numerator self term, draw provenance/order and strict versus inclusive membership. Distinguish supplied model probabilities, classwise p-values, prediction sets and optional truth-exclusion outputs. Give test-truth input and diagnostic output different IDs; an input-to-itself relation misstates the dependency. Keep source conflicts and simulation boundaries in the spec, figure and caption. The finite example has11elements/6relations and retains its original source disagreement.

## Confusion-count display fields
Record ordered truth/assigned-label axes, the absolute-count source range, counted units and repeated-annotation design separately. State row versus column conditioning, exact denominator and zero-support policy. Missing matrices must be absent from the supplied input, with dependent values and totals withheld. A local transformation has its own task definition; do not cite the specification itself as evidence for published methods. Pin a paper-specific adapter's accepted source identities so changed counts cannot silently retain that paper's attribution. Source/full-data rights and local test status remain separate.

## Grouped-score evaluation fields
Record score polarity, positive label, complete versus absent truth, threshold inequality, equal-score membership, class weights and original row count. Map ROC and PR numerator/denominator roles explicitly. Distinguish whole-group cutoff markers from count-mixture points; specify interpolation and undefined precision at zero selections. A case-mix weighting is a separate local assumption with synchronized baseline and caption. Source figure-number/envelope disagreements remain conflicts, not silently corrected methods. [Worked specification and exports](../tests/batches/precision-recall-01/DELIVERY.md).

For sampling diagrams, record coordinate order, units, positive directions, domain/codomain and boundary policy. Give depicted output/sample points resolvable element IDs and source/adaptation evidence. Missing displacement leaves sampling coordinates, weights and intensity unknown; do not default to zero. Distinguish an input/style recipe replay from arbitrary native-layout editing. [Finite example](../tests/batches/registration-warp-01/DELIVERY.md).

For graph diffusion preserve graph direction/weights, node and passage order, count/incidence distinction, query seed mapping and its presence/absence, probability convention, intermediate state fields and unexecuted upstream stages. Specificity-off removes its dependency edge and synchronizes values/caption; repeated-count changes can alter document scores without changing document frequency or node mass.

RNA-velocity fixtures record supplied versus inferred abundances/rates, coordinate and component order, display multiplier, component nullclines, full-vector stationarity, time-unit limits and unexecuted fitting. At fixed states alpha changes du only, gamma changes ds only. Missing alpha retains beta*u-gamma*s while du/full vectors/equilibrium remain unknown; synchronize labels, table, geometry and caption.

Receive-delay fixtures record transmit and return times, per-channel recording starts, sampling frequency/units, zero-based indices, interpolation/endpoint policy, supplied versus adaptive weights, normalization and signed aggregation. Missing weights preserve computable indices/amplitudes while contributions/sum remain unknown; do not substitute uniform weights. Keep source geometry and envelope/log conventions unresolved unless actually supported.

First-event result specs record source raw-to-time/event mapping, cause codes, entry assumptions, units, group denominators, censoring convention, administrative cutoff boundary and excluded later transitions. Separate development answer-bearing protocols from runtime briefs: an omitted input field is not genuinely missing if the specification still supplies its values. Test public-row identity without depending on row order.

Attribution recipes record model/output definition, feature units, baseline, path parameterization, numerical rule, step count and absolute or relative tolerance with its denominator. Baseline changes propagate to all dependent series and captions; approximation changes preserve exact references. A small total residual alone is not a proof of component-wise accuracy or explanation faithfulness.

Deconvolution operator specs record gene/type IDs, matrix axes, the full or selected gene universe, size units/provenance, ID join policy, design scaling, raw fitted coefficients, closure denominators and included types. Common size-unit scaling and relative size-assumption changes require different update rules. A marker subset cannot inherit complete-gene normalization assumptions without separate evidence.

Embedding operator specs record point IDs, matrix row/column identities, zero-diagonal policy, ordered-pair normalization, cost log base, derivative convention, applied step and fixed versus recomputed gradient. Unknown coordinates propagate to W/Q/G/update/cost. Appearance invariance excludes intentional RGBA changes but retains exact values, geometry and semantic bindings.


Residual-interval specifications record calibration-case IDs, predictor provenance/fitting status, absolute-score polarity, observation multiplicity, calibration count versus total-data notation, exact rank expression, overflow policy, interval closure, trial-response identities, and absence/presence of new truth. Bind mathematical infinity separately from a finite display window. A named nominal miscoverage parameter is not an observed error fraction. Pin the bytes actually consumed by the renderer, in addition to resolving source paths. [Finite split-conformal example](../tests/batches/split-conformal-rank-01/README.md) retains its source scope, metadata corrections and strict text-position failure.


For medical-volume views, record storage shape/order, zero-based index and center/edge convention, dtype/scaling, spatial units, applicable transform codes/matrix, plane axes/directions, selected voxel/world point and exact source hash. Separate raw intensities from window/clipping/quantized display matrices. An index change records Q from new indices to old, the actual reordered array, Anew=AoldQ and the corresponding point; a genuine point move updates planes, crosshairs, coordinates, values and caption. Record full-voxel image bounds, physical-to-page scale and scale-bar length. [One finite MRI derivative](../tests/batches/medical-volume-reindex-01/README.md) exercises this contract; it does not validate arbitrary NIfTI headers or physical reference truth.
